# WeatherMerger

Good day!

Tired of sticking to only one weather forecasting website?

WeatherMerger is here to merge all your weathering needs!

Combined weather forecasts from different weather providers at the same time to show on the same page!

Click this link to use: [link isn't public yet hihi]

Scope of Project
- Choses Closest Weather Station depending on selected Location (or long and lat entry)
- Uses most recent available data is used
- Caches previous searches
- ISO 8601 timestamping


Future Updates:
- Interactive Map
- Request User Real Time Position
- WMore eather Models?

Sources Used:
- Deutscher Wetterdienst (Observed Data, usually delayed by 12 hours)
- MET Norway (6 hour forecast based on coordinates)
- Open-Meteo
- National Oceanic and Atmospheric Administration (NOAA)
- National Weather Service
- WeatherAPI.com
- Nominatim (reverse-geocoding API)

Sources Not Used:
- AccuWeather's terms "Developer agrees that the License does not allow and Developer will not: commingle or supplement API Data from the APIs with any other weather information; use the APIs or the API Data to disparage, rate, rank, review or otherwise evaluate AccuWeather or its services and products;" [https://developer.accuweather.com/documentation/terms-of-use]
